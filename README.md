# Going, Going, Gone! — How to play

An interactive classroom companion for an art-auction board game: rules, a card and space guide, an auction practice mode with computer bidders, a set-math explainer, and a game-night helper (catalogue, auction mode for a projector, scoring).

🌐 **Play it:** https://andrew-wzj.github.io/going-going-gone/

Single static page (`index.html`). Player names, scores and photos are saved only in your own browser.
